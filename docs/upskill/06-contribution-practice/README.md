# Contribution Practice

These tickets turn reading into contribution practice. They are intentionally scoped from safe docs/tests to senior design work.

Use realistic OSS habits:

- Read first, then change.
- Keep PRs small.
- Avoid drive-by refactors.
- Explain tests, risks, and follow-ups.
- Respond to review with evidence, not defensiveness.

Start with `01-good-first-tickets.md`, then choose one ticket from each later file.
